# Fonts used by the Paper look

The files in `app/src/main/res/font/paper_*.ttf` are unmodified static instances from Google Fonts, under the
SIL Open Font License 1.1. Each family's licence and copyright notice is in this folder.

| paper_archivo_*.ttf | Archivo | archivo-OFL.txt |
| paper_playfair_*.ttf | Playfair Display | playfairdisplay-OFL.txt |
| paper_serif_*.ttf | Source Serif 4 | sourceserif4-OFL.txt |
